そだち手帳 よくある質問

記録はどこに保存されますか？

お使いのiPhoneと、ご自身のiCloudアカウントの中だけに保存されます。開発者のサーバーには送られず、開発者が記録の内容を見ることはできません。詳しくはプライバシーポリシーをご覧ください。

iPhoneを買い替えたら、記録は引き継げますか？

新しいiPhoneで同じApple IDにサインインし、iCloudがオンになっていれば、記録は自動で同期されます。念のため、買い替えの前に「設定」の「データを書き出す」でバックアップのファイルを作っておくと安心です。

記録をすべて消したいときは？

アプリの「設定」にある「すべてのデータを初期化する」で、iPhoneとiCloudの両方から消せます（同じApple IDのほかのiPhoneからも消えます）。アプリを削除しただけでは、iCloudの記録は残ります。

料金はかかりますか？

無料でお使いいただけます。お子さんの登録人数にも制限はありません。

予防接種の時期は、アプリのとおりに受ければよいですか？

アプリに表示される時期は、公的機関などが公表しているスケジュールにもとづく一般的な目安です。実際に受ける時期は、かかりつけの医師やお住まいの自治体にご確認ください。
